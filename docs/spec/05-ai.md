# 05 — Opponent AI (ai.C, follow.C) — spec (in progress)

Our-words functional spec from decompiled AI_Com_Server @0x431374, Determine_AI @0x432c4c,
Track_Follow @0x426ec4. Runs once per AI car per control step (alternate sim frames, see 03-gameloop).
Outputs into the car's control fields; the physics (04-handling) then integrates them.

## Inputs / outputs (per-car struct, stride 0x1b2)
- OUT steer angle @0x75a682 (Q12, clamped ±0x200 per step), throttle/brake @0x75a686 (Q12, e.g. ±0x4000).
- IN: barrier-hit mask @0x75a7ae, collision-side flag @0x75a6ca, OOB flag @0x75a6c6, motion state @0x75a692,
  aggression/ram timer @0x75a7af, ram-target car index @0x75a78a, lap/progress @0x75a67a.
- Track heading from the waypoint/strip table: per-car track-position struct stride **0x27c**, heading
  field @0x752392 (Q12 angle, &0xfff). Angle of a vector via FUN_00423804 (atan2-style → Q12).

## Control flow (AI_Com_Server)
1. Early-out: if OOB (@0x75a6c6) or motion state == 5 (rolled) → zero steer+throttle, return.
2. ARENA / derby levels (`_current_level > 7`, i.e. the bowls/arenas LEV8..B): aggressive behaviour.
   - On barrier/car contact (hit mask set), bias steering by collision side, set aggression timer 0x28 (40),
     and lock a ram target (@0x75a78a). While the timer runs, drive toward the target car: compute the
     angle between this car's heading and the bearing to the target (Q12, wrapped to ±0x800), steer to
     reduce it (clamped ±0x200), full throttle; reverse/steer-away if mis-aligned. (This is "Destruction
     Derby" ramming AI.)
3. CIRCUIT levels (racing): follow the racing line — desired heading = track waypoint heading; steer to
   minimise (carHeading − trackHeading) wrapped to ±0x800, clamped ±0x200; modulate throttle for corners
   (lift/brake when heading error large). Determine_AI / Track_Follow select the waypoint/segment and the
   target speed. (TODO: read Determine_AI + Track_Follow in full for the exact line-pick + speed table.)

## Angle conventions
- Q12 angles: 0x1000 = full circle, 0x800 = 180°, signed wrap to ±0x800 by `((a+0x800)&0xfff)-0x800`.
- Steering accumulates toward a target each step (rate-limited ±0x200), not set instantly — gives the
  characteristic AI steering lag.

## Determinism / port
- AI is deterministic given car/track state + fixed call order (player car driven first, then AI 1..n in
  index order — see Play_Game). Implement the same Q12 angle math + per-step clamp; no RNG in steering
  (any randomness, e.g. ram-target pick, must use the game's seeded source to stay deterministic — verify).

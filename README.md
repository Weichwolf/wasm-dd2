# wasm-dd2

A readable, modular C11 reimplementation of Destruction Derby 2 for Native and
WebAssembly with SoftGL. The rewrite lives on `master`; `ghidra` preserves the
decompiled and patched reference. Development is ongoing, and original game
data is provisioned separately.

Architecture, setup and current features: [docs/rewrite.md](docs/rewrite.md).
Backlog: [board/README.md](board/README.md).

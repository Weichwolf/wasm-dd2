# wasm-dd2

A modular C11 Destruction Derby 2 rewrite for Native and WebAssembly with SoftGL,
aiming for substantially improved graphics/audio and entirely rebuilt assets.
Standalone operation is under development. `master` contains the rewrite;
`ghidra` preserves the decompiled reference.

Architecture, setup and current features: [docs/rewrite.md](docs/rewrite.md).
Backlog: [board/README.md](board/README.md).

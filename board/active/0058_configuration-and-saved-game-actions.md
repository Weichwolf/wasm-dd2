Title: Configuration and saved-game application actions

## Contract

Connect original-compatible configuration, records and saved championships to
actual Native/browser application actions through the proved durable store.
Validate consumed fields before changing live state, retain selected physical
identity, reject corrupt/unsupported playable state without mutation and preserve
pending owners on close. Persist rewrite music gain explicitly; the original
controller field is not music volume. Keep original profile data and reserved
bytes through edits. Expose failure and completion accurately to the user.
